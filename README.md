## 上传到 GitHub

1. 解压 ZIP。上传解压后里面的全部内容，不要上传 ZIP 本身，也不要只上传 index.html。
2. 仓库最外层应直接包含 index.html、about/、additional/、projects/、assets/、media/ 和 .nojekyll。
3. 在 GitHub 仓库的 Settings → Pages 中，选择 Deploy from a branch、main、/(root)，然后 Save。
4. 等部署成功，使用 GitHub Pages 显示的网址。不要把仓库页面网址当成作品集网址。

如果用网页上传，可以分批上传文件夹；保持目录结构不变。
官方说明：https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site

## 后续更新

不包含原网站的登录、编辑后台、数据库和上传接口。原网站后台的更新不会自动同步到 GitHub；更新时重新导出或修改相应 HTML/图片，再上传替换。
